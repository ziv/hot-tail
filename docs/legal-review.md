# Legal review (K9) — release candidate

Not legal advice: a practical checklist for a free, ad-free web game. Get a professional clearance before any commercial use.

## Naming and originality

| Check | Result |
| --- | --- |
| Title | **Hot Tail** (placeholder "SKYFIRE" retired in M3). A public web search (Sep 2026) found no game with this name; the closest is *Hot On the Tail* (itch.io), an unrelated noir stealth game. No formal USPTO/EUIPO search was done — do one before registering or selling. |
| "After Burner" / Sega | No Sega names, logos, characters, music or assets anywhere in the shipped game. In-game text says "BOOST" rather than "afterburner"; the npm package is `hot-tail`. The design-reference document in the repo (`Afterburner-Style…Outline.md`) is internal and not deployed. |
| Aircraft | Kestrel, Dart and Manta are fictional designs built from primitives; bosses and enemies are original. Real aircraft names (e.g. "Raptor") were deliberately avoided. |
| Music & sound | Procedurally synthesised at runtime from original note data in `src/audio/music.ts`; no samples, no third-party audio. |
| Art | Everything is generated in code (`src/render/models*.ts`, shaders, canvas textures). Icons are generated by `scripts/make-icons.mjs`. |
| Credits | Names Ziv and Claude (Anthropic); generic nod to "the super-scaler arcade games of the 1980s". |

## Third-party software

All shipped dependencies are permissively licensed (MIT / 0BSD) — see [THIRD_PARTY_NOTICES.md](./THIRD_PARTY_NOTICES.md); full texts ship at `/licenses.txt`, regenerated on every build (the build fails if a non-permissive licence appears).

## Privacy

- Policy: `/privacy.html` (linked from Settings → Gameplay). Set `CONTACT_EMAIL` in the Vercel project so the contact line is filled in.
- No cookies, ads or third-party trackers → no consent banner required. Anonymous stats and error reports have an in-game opt-out.
- Leaderboard: callsign, random player ID, salted IP hash, run inputs. Players can erase their scores in-game (right to erasure).
- Processors: Vercel (hosting), Supabase (database) — both offer standard DPAs on free plans.

## Hosting terms

- Vercel Hobby is for non-commercial use — fine for a free game without ads. Moving to ads or paid features would require the Pro plan.
- Supabase Free: no commercial restriction; pauses when idle (the uptime workflow keeps it active).

Not chosen yet — the repository is currently "all rights reserved" by default. Decide before publishing the source (e.g. MIT for code, separate terms for the game name/branding).
